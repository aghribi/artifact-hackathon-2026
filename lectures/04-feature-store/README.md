# Feature Store

**Speaker:** Lex Avstreikh (Hopsworks)
**Slot:** Monday, October 12 (concepts) + Tuesday, October 13 (recap + 2h hands-on)

## Abstract

What a feature store is, and why it matters for machine learning on accelerators: post-mortem buffers, archiver data, simulations and logbooks turned into features, training data that is point-in-time correct, and the same features served to a live model. The Tuesday hands-on runs these steps on SPIRAL2 LLRF fault data, then on each team's own challenge dataset.
